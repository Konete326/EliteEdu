# EliteEdu

A modern Multi-Tenant School Management System built on the MERN stack.

## Architecture & Features
- **Multi-Tenancy:** Secure data isolation by school tenant.
- **Role-Based Access Control:** SuperAdmin, Admin (Principal), Teacher, and Student portals.
- **Frontend:** React 19, Vite, Tailwind CSS v3, Lucide icons.
- **Backend:** Node.js, Express, MongoDB Atlas, JWT authentication.
